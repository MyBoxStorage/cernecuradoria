# Cerne Curadoria — Site Institucional

Site institucional da Cerne Curadoria (Next.js 16, App Router, CSS puro com tokens do Design System).

## Desenvolvimento

```bash
npm install
npm run dev
```

## Variáveis de ambiente

Copie `.env.example` para `.env.local` e preencha conforme necessário. Ver Sprint 0 para os passos manuais (Vercel, GA4, Search Console).

## Scripts

- `npm run dev` — desenvolvimento local
- `npm run build` — build de produção
- `npm run start` — servir build
- `npm run lint` — ESLint
